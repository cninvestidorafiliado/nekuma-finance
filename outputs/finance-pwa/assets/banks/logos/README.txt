LOGOS DOS BANCOS

Coloque nesta pasta imagens PNG, de preferencia com fundo transparente.
Use estes nomes para os bancos ja reconhecidos pelo aplicativo:

- yucho.png
- nubank.png
- caixa.png
- santander.png
- bancodobrasil.png

Para contas sem um banco reconhecido, use:

- outros-japao.png
- outros-brasil.png

Tamanho recomendado: 256 x 256 pixels, com a logo centralizada e margem interna.
